Saiba quando o Claude precisa de você.

Monitor de sessões do Claude Code nos seus terminais. Uma bolinha discreta na tela que avisa quando uma sessão faz uma pergunta, termina ou trava, sem você ficar alternando de janela.

$ recursos

● sessões em tempo real

Todas as sessões do Claude Code abertas em qualquer terminal, com nome, tarefa atual e tempo decorrido.

● avisa quando espera você

O âmbar é a única cor do sistema e só aparece quando o Claude faz uma pergunta ou pede permissão. Impossível ignorar, impossível distrair.

▸ alertas por voz

Opcional: o aviso vira fala com as vozes Faber ou Santa. Útil quando você está longe da tela.

❯ contexto sempre à vista

Uso de tokens de cada sessão na barra do painel. Você sabe quanto contexto resta antes de continuar.
